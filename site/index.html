Conventions you already know

Symfony-style controllers and role hierarchy, declarative route validation, and a diff-based migration workflow.

controller/post.rs
// Role check + path-param validation injected by the macro.
#[karbon::controller(prefix = "/api/v1/posts")]
impl PostController {
    #[karbon::get("/{id}", id = "int:min=1")]
    async fn show(State(s): State<AppState>, Path(id): Path<i64>)
        -> AppResult<impl IntoResponse> {
        Ok(Json(Post::find_by_id(s.db.pool(), id).await?))
    }
}
terminal
# Scaffold from typed fields — no migration written here.
$ karbon generate crud Post title:string body:text published:bool

# Entities are the source of truth — diff them vs the DB.
$ karbon migrate diff init
  + table posts
  ✓ 1 change → migration/0001_init.sql

$ karbon migrate            # apply
$ karbon dev                # hot-reload + Studio cockpit
The dev cockpit

See your whole app while you build it

Studio is a browser dashboard embedded in dev mode — not a separate service to run. Live metrics, a schema and route explorer, and an integrated terminal that scaffolds for you.

  • Live latency, status & endpoint breakdowns
  • Schema browser and a classified route map
  • A whitelisted terminal with a visual field builder
  • Your project docs, rendered inline
