Installation

Karbon needs a Rust toolchain and, for full-stack projects, Node.js. Install the karbon CLI once and use it for every project.

Prerequisites

ToolVersionNeeded for
Rust1.82+ (edition 2024)Everything — the framework and CLI are Rust
Node.js18+The frontend (SvelteKit / Next.js). Not needed for --skeleton micro
A databaseMySQL 8 / MariaDB, PostgreSQL 13+, or SQLiteOptional — apps can run without one

Install Rust with rustup if you don't have it:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustc --version   # should print 1.82 or newer

Install the CLI

The CLI is published on crates.io:

cargo install karbon-cli

This installs a karbon binary into ~/.cargo/bin (make sure that's on your PATH). Verify it:

karbon --version
karbon --help

Updating. Re-run cargo install karbon-cli to upgrade to the latest published version. Add --force to reinstall the same version.

Check your environment

Karbon ships a diagnostic that flags common setup problems offline:

karbon doctor          # toolchain, project layout, config sanity
karbon doctor --db     # also probes the database connection & pending migrations

doctor exits non-zero if it finds a blocking problem, so it's safe to run in CI.

Developing against a local checkout

The published crates pin a stable API. If you want to build against an unreleased version of the framework — for example to use the studio feature or to contribute — clone the repo and scaffold with --local:

git clone https://github.com/larevuegeek/karbon
cd karbon
cargo build -p karbon-cli
./target/debug/karbon new demo --skeleton micro --local .   # . = the karbon checkout

With --local, the generated project's karbon dependency points at your checkout (a path dependency, with the studio feature enabled) instead of crates.io. Running karbon doctor in a project warns you when a dependency points at crates.io but you meant to use --local.
