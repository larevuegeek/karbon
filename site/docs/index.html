Karbon documentation

Karbon is a batteries-included full-stack framework for Rust. It pairs an Axum-based web core with a SvelteKit or Next.js frontend, and ties them together with a single CLI that develops, scaffolds, migrates and deploys your app.

The pitch: the productivity of Laravel and Symfony, with the safety, performance and single-binary deployment of Rust. No runtime, no garbage collector, no VM — just one compiled executable.

Why Karbon

Rust has excellent libraries, but assembling a productive full-stack app usually means wiring a dozen crates together by hand: a router, an ORM, auth, validation, migrations, background jobs, a frontend build, a deploy pipeline. Karbon makes those decisions for you and exposes them behind familiar conventions.

  • One CLI for the whole lifecycle — new, dev, build, serve, generate, migrate, deploy, doctor.
  • Convention over configuration — Symfony-style controllers, a role hierarchy, an entity-first ORM.
  • A real dev cockpit — Studio, a browser dashboard with live metrics, a schema/route explorer and an integrated terminal.
  • Safe by default — Argon2 passwords, JWT with refresh rotation, CSRF, declarative route validation, injection-safe queries.
  • Ship a single binary — to a VPS, Docker, or a PaaS, with configs generated for you.

What's in the box

AreaWhat you get
HTTPControllers via macros, middleware (compression, CSRF, rate limit, request-id), reverse proxy, graceful shutdown
DatabaseMySQL / PostgreSQL / SQLite, CrudRepository, a typed SelectBuilder, Insertable/Updatable derives, relations
MigrationsVersioned, native (sqlx), and a Doctrine-style migrate diff from your entities
SecurityJWT + refresh rotation, Argon2id, role hierarchy, AuthGuard, declarative route validation, secure uploads
RealtimeWebSocket channels & rooms, LiveWire components, Inertia.js adapter, HMR
Async workBackground jobs, a Symfony-Messenger-style message bus, an event bus, persistent queues
Building blocksForms, a composable validator, cache (memory/file/Redis), mail, i18n, image processing, scraping
ToolingCode generators, Studio cockpit, OpenAPI + Swagger UI, embedded docs, doctor diagnostics

Status & license

Karbon is published on crates.io as three crates — karbon-framework, karbon-macros and karbon-cli — and is pre-1.0: the API evolves between minor versions. It was extracted from LaRevueGeek.com, a Rust + SvelteKit magazine, and is released under the AGPL-3.0 license.
